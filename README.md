# MySQL Basics – Database Practice

## About This Project
This repository contains my beginner-level MySQL practice exercises. I created three databases and their respective tables to understand the fundamentals of database management.

## Databases Created

1. **training_lab**
   - Table: students
   - Columns: student_id, student_name, email, city, course_name

2. **library_db**
   - Table: book
   - Columns: book_id, title, author_name, category, published_year

3. **company_db**
   - Table: employee
   - Columns: employee_id, employee_name, dept, job_role, work_city, joining_year

## SQL Concepts Practised
- CREATE DATABASE
- CREATE DATABASE IF NOT EXISTS
- USE DATABASE
- CREATE TABLE
- CREATE TABLE IF NOT EXISTS
- SHOW DATABASES
- SHOW TABLES
- DESCRIBE / DESC

## Objective
To understand basic SQL commands and gain practical experience in creating and managing databases and tables using MySQL.
